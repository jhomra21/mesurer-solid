# Responsive inspector

Responsive opens with one iPhone 15 preview at 393 × 852 CSS pixels. Add up to six previews from the preset and breakpoint list. Each preview has independent width and height controls, removable/reorderable headers, and same-origin live iframes. Width and height are rounded and clamped to 240–3840 CSS pixels. Duplicate sizes are not added; adding a seventh distinct size replaces the last preview. Preview order changes visually without moving iframe nodes, so reordering does not reload pages.

Fit scales every preview by the same factor, using the largest viewport and the available stage space. Manual zoom levels are available from the control bar. Preview list, zoom, and per-preview Guides remain in memory for this page while Responsive closes and reopens. They reset when the page key (origin, pathname, or query) changes, and are never persisted to storage.

With Guides active, drag in a preview to create a guide, select and drag it to reposition, hold Shift to multi-select, hold Alt to show distance evidence, press Delete to remove only selected preview guides, or drag a guide beyond the preview edge to remove it. Guides snap to elements in that preview's own document and are stored in its CSS-pixel coordinates. Root-page guides are hidden and cannot be edited while the stage is open; they remain unchanged and reappear when it closes. Zoom does not change guide coordinates. Leaving Guides mode keeps the evidence visible but disables its interaction layer.

Rulers remain page-scoped. Activating Rulers closes Responsive so page rulers are shown on the original page rather than projected into previews. When Layout Guides is enabled, its shared page settings are projected into each preview at that preview's width; this does not create separate Layout Guide settings or change page-scoped Layout Guide state.

While the stage is open, its same-origin preview is the active inspection source. Select hover, click and marquee selection, measurements, X-ray, and Typography inspect elements in the preview, including accessible nested same-origin frames. Evidence is projected into Mesurer's root overlay at the scaled preview position. The original page and the stage chrome are not inspection sources while the stage is open. Closing the stage clears preview selection and hover state.

Context can annotate preview selections. Each element target adds `viewport: { url, width, height, previewId }` and a `domPath` for nested same-origin frames and open shadow roots, preserving the selector, fingerprint, immutable baseline, and existing root viewport CSS-pixel geometry. URL identity excludes the fragment but includes the pathname and query. Markers, panels, and the composer stay in the root overlay; Mesurer does not mount another Context UI in the preview document.

Only preview notes appear while Responsive is open; only root-page notes appear while it is closed. Resolution requires the exact URL, width, and height. The original preview id wins when still present; a recreated preview may rebind only when exactly one viewport matches and the stored selector/fingerprint resolves conservatively. Missing or ambiguous targets stay unresolved. Resizing a preview away from the saved size hides its notes until the exact viewport returns. No note migrates to a same-width/different-height viewport or another route.

Preview notes require selected elements within one preview; empty regions and selections spanning different previews cannot create a note.

Removing a preview immediately releases its Context document watchers and hides its markers/panels, but keeps the saved records. Closing Responsive releases preview documents and transient selection/composer state while retaining records. Reopening reloads the retained sizes at the current root URL and rebinds matching notes. Notes retain Context's page-keyed same-tab session persistence, independently of Responsive's in-memory settings; after a page-key change, only that page's notes are loaded, and returning to the old page restores its records. Reload resets preview settings, not saved notes. Deleting a preview note through its panel affects only that annotation; Delete in a preview never deletes root-page notes.

`annotations()` exposes the saved descriptor, and `context()` exposes it per target and as `previewViewport` for preview evidence. `capturePlan()` includes `previewViewport` with root-projected capture geometry. `coordinateSpace` remains `"viewport-css-px"` in the root viewport. `window.__MESURER__` keeps its existing methods: selector-based `inspect()`/`select()` remain root-scoped, while selection/annotation Context reads the actual human-selected preview target.

The page must allow itself to load in same-origin iframes. Cross-origin frames, `X-Frame-Options`, CSP `frame-ancestors`, and frame-busting code can prevent that. Mesurer shows a refusal message when it cannot access the loaded document; inspection then finds nothing in that refused preview.

Previews reload the live page in same-origin iframes and run its JavaScript. Requests, analytics, and other page side effects repeat for every preview that is added. Up to six live documents can consume substantial memory and network resources. The iframe sandbox suppresses some browser actions, but it is not a security boundary. Use Responsive only on pages whose scripts you are willing to run again.

The page behind the stage is scroll-locked while Responsive is open. Wheel input over the empty stage moves only the preview row; wheel input inside a frame scrolls that preview and hands horizontal movement to the row when possible. Closing Responsive restores the page's prior inline `overflow-x` and `overflow-y` values and priorities. A page-key change while the stage is open closes it and resets the in-memory preview state.

Entering Responsive exits Edit, clears the current selection, and closes the preview when Edit, Rulers, Screenshot, or Recording is activated. B is ignored by editable controls, including open Shadow DOM inputs in the preview. Turning off global shortcuts disables B without disabling Escape.

Responsive is on by default. Turn it off in **Settings > Plugins**, or omit it with `excludeBuiltins: ["responsive"]`. Press **B** to open or close it; Escape and a click on the empty stage also close it.
